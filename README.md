Simple Form Website
A lightweight HTML form that can be deployed using GitHub and Vercel.
Features
Responsive white form design
Replaceable logo
Editable heading and description
Two visible text fields
Continue button
Configurable redirect destination
No database required for the demonstration
Customize the website
Open index.html to change the page title, heading, description, input labels, and destination URL.
To change the redirect destination, update the DESTINATION_URL constant in the JavaScript section.
To change the logo, add your image to the project folder as logo.png.
Deployment
Create a GitHub repository.
Upload index.html and README.md.
Sign in to Vercel using GitHub.
Import the repository.
Deploy the project.
Open the deployment URL and test the website.
Important
This is a front-end demonstration. It does not store form submissions or include an administrator dashboard.
